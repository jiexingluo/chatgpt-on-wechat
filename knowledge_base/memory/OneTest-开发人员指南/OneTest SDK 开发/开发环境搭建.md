开发环境搭建

在SDK开发的项目中，需要引用以下DLL (具体以实际安装路径为准))：

* 1.Guwave.OneTest.Client.SDK

  *默认路径："C:\Program Files\Gubo\OneTest\SDK\Guwave.OneTest.Client.SDK.dll"*
* 2.Guwave.OneTest.Common

  *默认路径："C:\Program Files\Gubo\OneTest\SDK\Guwave.OneTest.Common.dll"*
* 3.Guwave.OneTest.Engine.Grpc

  *默认路径："C:\Program Files\Gubo\OneTest\SDK\Guwave.OneTest.Engine.Grpc.dll"*

在SDK开发的项目中，还需要引用以下NuGet包：

* 1.Grpc.Core (Version="2.46.3")

示例csproj文件

Example Project

[复制](# "复制")

```
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <OutputType>Exe</OutputType>
    <TargetFramework>net7.0</TargetFramework>
    <ImplicitUsings>enable</ImplicitUsings>
    <Nullable>enable</Nullable>
  </PropertyGroup>
  <ItemGroup>
    <Reference Include="Guwave.OneTest.Client.SDK">
      <HintPath>c:\Program Files\Gubo\OneTest\SDK\Guwave.OneTest.Client.SDK.dll</HintPath>
    </Reference>
    <Reference Include="Guwave.OneTest.Common">
      <HintPath>c:\Program Files\Gubo\OneTest\SDK\Guwave.OneTest.Common.dll</HintPath>
    </Reference>
    <Reference Include="Guwave.OneTest.Engine.Grpc">
      <HintPath>c:\Program Files\Gubo\OneTest\SDK\Guwave.OneTest.Engine.Grpc.dll</HintPath>
    </Reference>
  </ItemGroup>
  <ItemGroup>
    <PackageReference Include="Grpc.Core" Version="2.46.3" />
  </ItemGroup>
</Project>
```
