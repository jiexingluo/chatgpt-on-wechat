|  |  |
| --- | --- |
|  | 2.1.TestMethod框架 |

2.1.TestMethod框架

* TestMethod在OneTest中通过点击项目菜单树中 >Test IPs > 新建测试IP > 输入TestMethod名称 >(可选)添加输入参数 > (可选)添加输出参数 > 创建
* TestMethod通过上述步骤创建成功后, OneTest即可基于模板生成如下TestMethod的code， code各部分含义详细介绍见code注释。

Testmethod example

[复制](# "复制")

```
using Guwave.OneTest.TestMethod;

namespace UserDefinedTestMethods
{
    [DefinedTestMethod("This is test method template")]
    public class newFile1 : TestMethod
    {
        // Define a Property for each Input Params
        [InputParam(DefaultValue="VCC1", Description = "Input Param1")]
        public string Pin { get; set; }

        [InputGroupParam("Group1.Param2", DefaultValue=0.5,  Description = "Input Param2")]
        [InputGroupParam("Group1.Param1", DefaultValue=0.3,  Description = "Input Param1")]
        public dynamic Group1 { get; set; }

        public ParametricTestDescriptor ptdCurrent { get; set; }

        public FunctionalTestDescriptor ftdTest { get; set; }      

        public override void Execute()
        {
            // Implement Test Method here.
        }

        //Property should align with TestMethod Attribute which is also generated by User Defined TestMethod Creator or added by end user
    }
}
```

## 2.2.TestMethod编写参数

|  |  |

2.2.TestMethod编写参数

* 输入参数为TestMethod执行中测试数据入口，可以是测试仪器配置参数等，输出参数将从仪器得到数据输出到UI界面，以供分析。
* 在TestMethod的执行过程中 InputParam会从UI 界面传入实时输入的测试数据进入仪器并实施测试。
* 目前支持两种类型的输入参数分别是InputParam 和 InputGroupParam

InputParam （InputParam 可定义单个输入参数在UI界面中以单行显示）

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| DefaultValue | int/ulong/long/double/bool/string | 必须 | 当前InputParam设置初始值 |
| Description | string | 可选 | 当前InputParam的描述信息 |
| OptionValue | string | 可选 | 当前InputParam的可选值，可在TestMethod执行前，在UI界面通过下拉框的方式选择当前InputParam 设定的待选择值 |
| CanDebug | bool | 可选 | 当前InputParam参数是否可调试，默认值为true，当配置为false时UI界面中InputParam的参数值不能被修改 |
| RelyParam | string | 可选 | 依赖参数的名称（其他已定义的InputParam的名称），当依赖参数的取值等于RelyValue时，该InputParam参数才能在UI界面显示 |
| RelyValue | string | 可选 | 依赖值，需配合RelyParam一起使用 |

InputGroupParam （InputGroupParam定义一个输入参数组，在UI界面中以一个折叠的树形显示一组相关的输入参数）

| 参数 | 类型 | 是否必须 | 说明 |
| --- | --- | --- | --- |
| DefaultValue | int/double/bool/string | 必须 | 当前InputParam设置初始值 |
| Description | string | 可选 | 当前InputParam的描述信息 |
| OptionValue | string | 可选 | 当前InputParam的可选值，可在TestMethod执行前，在UI界面通过下拉框的方式选择当前InputParam 设定的待选择值 |
| CanDebug | bool | 可选 | 当前InputParam参数是否可调试，默认值为true，当配置为false时UI界面中InputParam的参数值不能被修改 |
| RelyParam | string | 可选 | 依赖参数的名称（其他已定义的InputParam的名称），当依赖参数的取值等于RelyValue时，该InputParam参数才能在UI界面显示 |
| RelyValue | string | 可选 | 依赖值，需配合RelyParam一起使用 |
| GroupRely | bool | 可选 | 参数组依赖 如果为true，当前组内同级及子级参数都会依赖RelyParam，子级的依赖关系将被覆盖 |

| --- | --- |
|  | 2.3.TestMethod输入参数与UI关系举例 |

2.3.TestMethod输入参数与UI关系举例

* 预先在TestMethod中定义好输入参数
* Debug 界面：重新编译后，Debug 界面会根据编写的TestMethod内容自动将输入参数加载到Parameter Settings表格中，如下图所示：

Testmethod example

[复制](# "复制")

```
// Define a Property for each Input Params
[InputParam(DefaultValue = "VCC", Description = "芯片上电引脚名称，如果执行当前操作时不需要上电，清空输入即可，SupplyParam相关参数不生效")]
public string SupplyPin { set; get; }

[InputParam(DefaultValue = "ADC_1_5", Description = "ADC的参考电压选择", OptionValue = "ADC_1_5,ADC_2_5,AVCC")]
public string ADC_Ref { get; set; }

[InputParam(DefaultValue = "PC04", Description = "ADC输入通道选择")]
//public string ADC_SampleSpeed { get; set; }
public string AINPin { get; set; }

[InputParam(DefaultValue = 2048, Description = "ADC的高阈值设置")]
public ulong HT { get; set; }

[InputParam(DefaultValue = 512, Description = "ADC的低阈值设置")]
public ulong LT { get; set; }

[InputGroupParam("SupplyParam.VForce", DefaultValue = 3.3, Description = "施加的电压值(V)")]
[InputGroupParam("SupplyParam.IClamp", DefaultValue = 0.032, Description = "钳位电流不相等时，较高的钳位电流值(A)")]
[InputGroupParam("SupplyParam.SenseMode", DefaultValue = "Local", Description = "是否采用四线制，如果采用，选择Remote", OptionValue = "Remote")]
public dynamic SupplyParam { get; set; }
```
