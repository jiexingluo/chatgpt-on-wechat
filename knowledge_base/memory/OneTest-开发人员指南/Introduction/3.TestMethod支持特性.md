## 3.4.ParametricTestDescriptor的使用

|  |  |
| --- | --- |
|  | 3.4.ParametricTestDescriptor的使用 |

3.4.ParametricTestDescriptor的使用

* ParametricTestDescriptor简称PTD
* PTD为参数测试，用于Testflow执行过程中添加测试项，可以对用户在TestMethod中获得的测量结果进行Evaluate和Publish
* 在TestMethod定义好PTD、Build项目成功后，Evaluation Settings面板中会自动更新PTD的相关信息。

TestMethod通过上述步骤创建成功后, OneTest即可基于模板生成如下TestMethod的code， code各部分含义详细介绍见code注释。

参数属性列表

| 名称 | 含义 |
| --- | --- |
| Test Number | 用户根据需求自定义，但是用户应确保Test Number在整个Test Flow中的唯一性。 |
| Test Text | 用户根据需求自定义，用于生成 std​​f PTR 记录的Test Text。 |
| Pin/PinGroups | 需要输出的Pin/PinGroups的信息或需要输出到报告中测试项名称 |
| TestDescriptor Name | 用户在TestMethod.cs文件中定义的ParametricTestDescriptor类型的属性名称 |
| Low Limit , Hight Limit | 用户根据需求自定义，用于evaluation测试数据的上限和下限。 |
| Scaling Factor | 用户根据需求从下拉框中选择合适的值对Low Limit, Hight Limit进行缩放，当只配置Scaling Factor 却不配置Units时，缩放功能将不起作用 |
| Units | 单位 |
| SoftBin | 用户根据需求从下拉框中选择，SoftBin下拉列表的数据源自 BinMap Editor。 |
| Hardbin | HardBin 相关信息将从根据选择的 SoftBin 自动创建。 |

ParametricTestDescriptor的使用用例

case1: Evaluate单个double值

Testmethod example

[复制](# "复制")

```
using Guwave.OneTest.TestMethod;

namespace UserDefinedTestMethods
{
    [DefinedTestMethod("This is a user generate TestMethod")]
    public class PTD_Evaluate_Double : TestMethod
    {
        public ParametricTestDescriptor PtdCurrent { set; get; }

        public override void Execute()
        {
            PtdCurrent.Evaluate(0.8);
        }
    }
}
```

case2: Evaluate（Dictionary<string, double>）

Testmethod example

[复制](# "复制")

```
using Guwave.OneTest.TestMethod;

namespace UserDefinedTestMethods
{
    [DefinedTestMethod("This is a user generate TestMethod")]
    public class PTD_Evaluate_Dic : TestMethod
    {

        public ParametricTestDescriptor PtdCurrent { set; get; }

        public override void Execute()
        {

            // 模拟测试数据
            double k = NextDouble(0.1, 1);
            double k1 = NextDouble(0.1, 1);
            double k2 = NextDouble(0.1, 1);
            Dictionary<string, double> vgResult = new Dictionary<string, double>
            {
                { "VG1", k },
                { "VG2", k1 },
                { "VG3", k2 }
            };

            PtdCurrent.Evaluate(vgResult);
        }

        private double NextDouble(double min, double max)
        {
            return min + (max - min) * Random.Shared.NextDouble();
        }
    }
}
```

case3: 在TestMethod中动态设置测试项参数

Testmethod example

[复制](# "复制")

```
using Guwave.OneTest.TestMethod;

namespace UserDefinedTestMethods
{
    [DefinedTestMethod("This is a user generate TestMethod")]
    public class PTD_Concat : TestMethod
    {
        [InputParam(DefaultValue = "F1T1,F2T2,F3T3,F4T4", Description = "Input Param1")]
        public string Pins { set; get; }
        public ParametricTestDescriptor PtdCurrent { set; get; }

        public override void Execute()
        {

            // 模拟测试数据
            Dictionary<string, double> PinResults = new Dictionary<string, double>
            {
                { "F1T1", NextDouble(0.1, 1) },
                { "F2T2", NextDouble(0.1, 1) },
                { "F3T3", NextDouble(0.1, 1) },
                { "F4T4", NextDouble(0.1, 1) }
            };

            string[] pinNames = Pins.Split(',');
            for (int i = 0; i < pinNames.Count(); i++)
            {
                // 在此处动态设置子测试项的配置参数（注意testName的值必须是测试数据中已定义的key否则设置不会生效）
                PtdCurrent.Concat(testNumber: 10000 + i, testName:pinNames[i], testText:"CurrentTest_" + pinNames[i]);
            }
            PtdCurrent.Evaluate(PinResults);
        }

        private double NextDouble(double min, double max)
        {
            return min + (max - min) * Random.Shared.NextDouble();
        }
    }
}
```

case4: 获取Evaluation的子级Evaluation配置参数的值

            var subTestName = subEvaluater.TestName;

            var subtestText = subEvaluater.TestText;
        }
    }

## 3.5.FunctionalTestDescriptor的使用

|  |  |
| --- | --- |
|  | 3.5.FunctionalTestDescriptor的使用 |

3.5.FunctionalTestDescriptor的使用

* FunctionalTestDescriptor简称FTD
* FTD为功能测试，用于Testflow执行过程中添加测试项，只有True和False的结果。
* 在TestMethod定义好FTD、Build项目成功后，Evaluation Settings面板中会自动更新FTD的相关信息。

参数属性列表

| 名称 | 含义 |
| --- | --- |
| Test Number | 用户根据需求自定义，但是用户应确保Test Number在所有Test Flow中的唯一性。 |
| Test Text | 用户根据需求自定义，用于生成 std​​f FTR 记录的Test Text。 |
| Pin/PinGroups | 需要输出的Pin/PinGroups的信息或需要输出到报告中测试项名称 |
| TestDescriptor Name | 用户在TestMethod.cs文件中定义的FunctionalTestDescriptor类型的属性名称 |
| SoftBin | SoftBin的下拉框数据源自BinMap Editor |
| Hardbin | Hardbin 相关信息将从选择的 Softbin 中生成。 |

注意：ftp在添加测试项的时候，Low Limit , Hight Limit列不填。
