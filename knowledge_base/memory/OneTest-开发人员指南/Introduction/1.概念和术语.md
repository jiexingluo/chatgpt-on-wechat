1.概念和术语

* TestMethod：芯片测试人员写的用于芯片测试的程序，OneTest支持使用C#代码编写芯片测试程序；

  TestSuite：回测数据的判断与比较（比如测取一下电流大小）会有数值合理范围（称为Limit），TestMethod + Limit形成TestSuite；

  TestFlow：TestSuite按照一定的规则组合的序列，运行时将按顺序和条件执行这一组TestSuite；
